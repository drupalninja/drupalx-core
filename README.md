# DrupalX Core

Core functionality for DrupalX decoupled Drupal distribution.

## Overview

This package provides the core functionality and components used by the DrupalX decoupled Drupal distribution.

## Features

* Core API functionality
* Base configuration
* Shared components and utilities

## Requirements

* Drupal 10+
* PHP 8.1+

## Installation

This package is not meant to be installed directly but is included as part of the DrupalX installation profiles.
